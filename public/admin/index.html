SK Dental Admin

Sign in with your GitHub Personal Access Token to edit the website.

How do I get a token?
  1. Open github.com/settings/tokens
  2. Click Generate new token (fine-grained)
  3. Name it skdental-admin, expiration 90 days
  4. Repository access: Only select repositories → skdental-site
  5. Permissions → Repository permissions → Contents: Read and write
  6. Click Generate token, copy it, paste above
